    Arquitectura Técnica en Godot

    Parte técnica del proyecto.

    Motor de Videojuegos: Godot Engine

    Versión: Godot 4.3 o superior (estable).

    Lenguaje de Programación: GDScript.

    Resolución y Estética:

    • Estilo visual Pixel Art combinado con elementos de interfaz de Windows XP.

    • Configuración de renderizado orientada a gráficos pixelados nítidos.

    Configuración Global del Proyecto.

    Para asegurar que los recursos visuales y las texturas de la interfaz clásica de Windows XP mantengan una definición nítida sin interpolaciones borrosas, se deben aplicar los siguientes parámetros en la configuración del proyecto (Project Settings):

    Escalado de Pantalla (Window Stretch):

    • Modo: canvas_items

    • Aspecto: keep

    • Filtrado de Texturas.

    • Filtro predeterminado: Nearest (Evita el suavizado lineal, manteniendo el aspecto de píxel nítido).

    Arquitectura y Estructura de Nodos del Jugador.

    El personaje principal se implementa utilizando un nodo de física cinemática para un control preciso de plataformas.

    Jerarquía de Nodos:

    • Player (CharacterBody2D) — Nodo raíz encargado de gestionar las físicas globales.

    • Sprite2D — Contiene la textura o fotogramas de animación de la silueta amarilla.

    • CollisionShape2D — Forma de colisión de tipo CapsuleShape2D o RectangleShape2D para interactuar con el entorno.

    • Camera2D — Cámara centrada en el jugador para el seguimiento de la acción en el escritorio.

    Especificación del Script de Movimiento (player.gd)

    El script base gestiona las físicas estándar de plataformas 2D, incluyendo gravedad, aceleración horizontal, inercia de frenado y salto vertical.

extends CharacterBody2D

## Velocidad máxima de movimiento horizontal en píxeles por segundo.
@export var speed: float = 200.0

## Velocidad de impulso vertical al saltar (valor negativo en el eje Y de Godot).
@export var jump_velocity: float = -400.0

## Gravedad obtenida automáticamente de los ajustes físicos del proyecto.
var gravity: float = ProjectSettings.get_setting("physics/2d/default_gravity")

func _physics_process(delta: float) -> void:
    # 1. Aplicación de la gravedad si el personaje no se encuentra sobre el suelo.
    if not is_on_floor():
        velocity.y += gravity * delta

    # 2. Gestión de la acción de salto.
    if Input.is_action_just_pressed("ui_accept") and is_on_floor():
        velocity.y = jump_velocity

    # 3. Lectura de la dirección de entrada (-1: Izquierda, 1: Derecha).
    var direction := Input.get_axis("ui_left", "ui_right")

    if direction:
        velocity.x = direction * speed
    else:
        # Frenado gradual cuando no hay entrada del usuario para evitar paradas bruscas.
        velocity.x = move_toward(velocity.x, 0, speed)

    # 4. Ejecución del movimiento físico integrado con detección de colisiones.
    move_and_slide()
